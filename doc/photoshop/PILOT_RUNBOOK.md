# Пилот: запуск в Photoshop (после исправления частотки)

**Область:** только несколько кадров на **вашем** Mac с установленным Photoshop. Вся съёмка и установка на компьютер Лизы — **после** успешных тестов здесь.

**Что делают скрипты сейчас:** повторяют **экшен** Лизы (цвет + фон) и **создают слои** частотного разложения. Это **не** автоматизация полной ручной ретуши (родинки, пушок, пластика, микс-кисть). После пилота основная разработка — **автовыравнивание пятен на коже без потери текстуры** (Pixmuse).

---

## Подготовка (один раз)

1. **Файл → Сценарии → Обзор…** → каталог `pixmuse/doc/photoshop`.
2. В **`ElizBatchColorButton.jsx`** вписать **ACTION_SET** и **ACTION_NAME** с панели «Операции» Лизы (для теста 3).
3. Для пилота girl1:
   - `PILOT_MODE = true`
   - `PILOT_MAX = 5`
   - `MODEL_PROFILE = "girl1"`
4. **Не** смешивать на одном кадре: экшен Лизы **+** `ElizCatalogColorStack.jsx`.

---

## Тест 1 — один кадр

1. **Файл → Открыть** → `doc/TSV_0035.cr3` (ACR как у Лизы → **Open**, обычно **16 bit RGB**).
2. Панель **Операции** → **только** экшен Лизы (один клик).
3. Сравнение с эталоном: открыть `doc/до после.psb` вторым документом → слой **«после»** (кожа, фон, бельё). Допустимы мелкие отличия из‑за другого кадра; смотрим **характер** коррекции.
4. Свести слои так, как делает Лиза после кнопки → выделить этот слой.
5. **Файл → Сценарии → `ElizFrequencySetup.jsx`**.
   - Документ должен быть **RGB**, **8 или 16 bit** (не 32-bit).
   - Появится группа **«частотка»**; слой **«исходник (сравнение)»** — **пиксели не менялись**, только скрыт.
6. Закрыть `TSV_0035` **без сохранения** (файл `.cr3` на диске не перезаписывается).

---

## Тест 2 — качество частотки (без ретуши)

Цель: убедиться, что разложение **не меняет** изображение до работы кистью.

1. На том же кадре после шага 5 теста 1 (или повторить экшен + частотку).
2. **Вариант A:** группа **«частотка»** включена, opacity группы **100%**, High — **Linear Light 100%** → картинка как после слияния (до частотки).
3. **Вариант B:** выключить **«частотка»** → включить **«исходник (сравнение)»** → сравнить с вариантом A (**100%**, кожа, цвет, мелкая текстура).
4. **Не** рисовать на масках и **не** трогать opacity High для этого теста (для работы Лиза может опустить High до ~50% — это уже этап ретуши, не тест идентичности).
5. При расхождении: зафиксировать **bit depth** (Image → Mode), версию PS, скрин слоёв; при необходимости сравнить Apply Image вручную с параметрами из `ElizFrequencySetup.jsx`.

---

## Тест 3 — пакет (после имени экшена)

1. Создать `doc/pilot_girl1/`, скопировать **3–5** CR3 **первой модели** (не вся съёмка).
2. **Сценарии → `ElizBatchColorButton.jsx`** → выбрать `pilot_girl1`.
3. Проверить:
   - `doc/pilot_girl1/_after_button/*.psd` (слои сохранены),
   - `doc/pilot_girl1/_after_button/batch.log` (OK / FAIL / SKIP),
   - исходные **`.cr3` не изменены** (дата/размер файла, повторное открытие CR3).
4. На **одном** PSD: слить → `ElizFrequencySetup.jsx` → тест 2; при OK — оценка ручного хвоста по `../CHECKLIST_LIZA.md`.

---

## Вторая модель

- Отдельный экшен/PSB от Лизы.
- `MODEL_PROFILE = "girl2"` + confirm в скрипте.
- **Не** применять пресет girl1 без подтверждённого экшена для girl2.

---

## Цепочка

```
CR3 → [только экшен Лизы] → (тест 3) PSD в _after_button/
     → слить → ElizFrequencySetup.jsx → ручной чеклист
```

---

## Критерий «можно ставить Лизе»

| Проверка | Где |
|----------|-----|
| Экшен ≈ эталон PSB | Тест 1 |
| Частотка on/off = исходник | Тест 2 |
| Batch + CR3 целы | Тест 3 |
| Один кадр доведён вручную по времени | Чеклист |

Успешные три теста **не** означают готовый конвейер ретуши — только безопасный пилот скриптов. Дальше: Pixmuse / выравнивание пятен.

---

## Чего не делать в пилоте

- Не гнать всю съёмку (~350 кадров).
- Не делать push / не разносить скрипты без вашего OK.
- Не использовать Polza вместо пилота CR3.

Статический разбор кода: **`PILOT_VERIFICATION.md`**.
