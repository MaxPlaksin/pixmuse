# Каталогная ретушь Лизы (пилот) + материалы

Параллельная ветка работ в репозитории **Pixmuse**: автоматизация **экшена «кнопки»** и **частотного разложения** для Canon CR3 (16 bit), без замены полной ручной ретуши.

## Что делаем

1. **Экшен Лизы** — цвет тела + фон (не дублировать `ElizCatalogColorStack.jsx`, если кнопка есть).
2. **`ElizFrequencySetup.jsx`** — частотка blur **7**, Low + High, Linear Light **100%** (8/16 bit).
3. **Ручной хвост** — `CHECKLIST_LIZA.md` (родинки, пушок, микс-кисть 53–55 / ~70).
4. **Pixmuse (основная разработка)** — позже: выравнивание пятен на коже без потери текстуры.

## Известный блокер

**ExtendScript `Apply Image` (`AppI`)** в **Photoshop 2026** падает с **-1715** при автозапуске; blur и слои создаются. Обход (записанная операция / другой API) — в работе. Офлайн-математика частотки сходится (`verify_frequency_math.py`).
