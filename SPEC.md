# Pixmuse MVP

## Цель

Локальное веб-приложение для фотографа: загрузить обработанный эталон, добавить
серию JPEG/PNG, адаптивно перенести цвет и контраст, проверить кадры и скачать
результаты ZIP-архивом.

## Стек

- React 19, TypeScript, Vite
- Canvas API для обработки изображений в браузере
- JSZip для локальной сборки архива
- Vitest для тестов алгоритма

На этом этапе сервер, база данных, аккаунты и внешние AI-модели отсутствуют.
Фотографии не отправляются в сеть.

## Команды

- Установка: `npm install`
- Разработка: `npm run dev`
- Тесты: `npm test`
- Сборка: `npm run build`

## Структура

- `src/App.tsx` - общая библиотека фотографий и переключение режимов
- `src/studio/PhotoEditor.tsx` - профессиональный редактор
- `src/lib/colorTransfer.ts` - перенос цвета эталона
- `src/lib/renderRecipe.ts` - неразрушающий рецепт обработки
- `src/lib/*.test.ts` - модульные тесты
- `src/styles.css` - адаптивная тема интерфейса

## Правила

- Не изменять оригинальные файлы.
- Обрабатывать серию последовательно для контроля памяти.
- При ошибке одного кадра продолжать обработку остальных.
- Поддерживать только JPEG/PNG до отдельной реализации RAW-конвейера.
- Не называть перенос цветовой статистики AI-ретушью лица.

## Критерии готовности

- Пользователь может выбрать один эталон и несколько исходников.
- Сила эффекта регулируется.
- Серия обрабатывается локально и показывает статус каждого кадра.
- Есть сравнение до/после.
- Готовые JPEG скачиваются одним ZIP.
- Модульные тесты и production-сборка проходят.
