# Pixmuse: текущая спецификация

## Цель

Локальное приложение для ретушёра: вручную обработать JPEG/PNG, сохранить
неразрушающий рецепт, применить цветовые параметры к серии, проверить
исключения и экспортировать результаты без изменения оригиналов.

## Стек

- React 19, TypeScript, Vite
- Canvas API и Web Worker для обработки изображений
- IndexedDB для локального проекта и контрольной точки
- JSZip для локальной сборки архива
- Vitest для тестов алгоритмов и хранилища
- Playwright и Chromium для E2E на настоящих JPEG/PNG fixtures

Сервер, аккаунты, платные API и внешние AI-модели отсутствуют. Фотографии не
отправляются в сеть.

## Команды

- Установка: `npm install`
- Разработка: `npm run dev`
- Тесты: `npm test`
- Сборка: `npm run build`
- Lint: `npm run lint`
- E2E: `npm run test:e2e`

## Структура

- `src/App.tsx` - режимы, пакетная очередь и проект
- `src/studio/PhotoEditor.tsx` - редактор одного кадра
- `src/lib/renderRecipe.ts` - неразрушающий движок рецепта
- `src/lib/colorTransfer.ts` - эталон и пакетная ретушь
- `src/lib/projectStore.ts` - IndexedDB v2, библиотека проектов и архив
- `src/workers/render.worker.ts` - предпросмотр редактора
- `src/lib/*.test.ts` - модульные и интеграционные тесты
- `src/styles.css` - адаптивная тема интерфейса

## Правила

- Не изменять оригинальные файлы.
- Обрабатывать серию последовательно для контроля памяти.
- При ошибке одного кадра продолжать обработку остальных.
- Записывать manifest и файлы проекта одной IndexedDB-транзакцией.
- При неудачной записи сохранять предыдущий целостный checkpoint.
- Не переносить координаты локальных мазков через пресеты.
- Поддерживать только JPEG/PNG до отдельной реализации RAW-конвейера.
- Не называть перенос цветовой статистики AI-ретушью лица.

## Критерии готовности текущего этапа

- Редактор предоставляет live preview, глобальные и локальные коррекции.
- Undo/redo хранит неразрушающие рецепты отдельно для каждого кадра.
- Пресет переносит цветовые настройки, но не локальные мазки.
- Серия поддерживает прогресс, паузу, отмену, повтор ошибок и тайм-аут.
- JPG/PNG экспортируются отдельно или ZIP-архивом.
- Проект восстанавливается из атомарной локальной контрольной точки.
- Несколько проектов изолированы друг от друга и старый проект мигрирует в v2.
- Clone переносит пиксели из явно выбранного источника только внутри кадра.
- Rule-based Quality Inspector анализирует резкость, клиппинг и похожие кадры.
- Тесты, lint и production-сборка проходят.
