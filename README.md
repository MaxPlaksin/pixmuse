# Pixmuse

Локальная фотостудия для неразрушающего редактирования JPEG/PNG и обработки
серий по эталону. Фотографии обрабатываются в браузере и не отправляются на
сторонние серверы.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала.

## Что реализовано

### Редактор

- Живой предпросмотр через Web Worker.
- Экспозиция, контраст, света, тени, белые и чёрные.
- Температура, tint, насыщенность, vibrance и HSL.
- Тоновая кривая, резкость и шумоподавление.
- Сглаживание кожи с регулируемым сохранением текстуры.
- Кадрирование, масштаб и поворот.
- Локальные инструменты Heal, Clone, Dodge и Burn. Clone использует выбранную
  пользователем область-источник.
- RGB-гистограмма, пипетка, предупреждения о клиппинге.
- История undo/redo и сравнение до/после.
- Пресеты без переноса локальных мазков на другие кадры.

### Серия

- Один эталон или рецепт редактора для нескольких фотографий.
- Локальный Quality Inspector отмечает возможный смаз, пересветы, провалы в
  тенях и визуально похожие кадры по perceptual hash.
- Очередь, прогресс, пауза, отмена и повтор ошибок.
- Тайм-аут отдельного кадра: 2 минуты.
- Экспорт JPG/PNG и ZIP, качество JPEG и ограничение размера.
- Явное освобождение готовых Blob из памяти после скачивания.
- Оригинальные файлы не изменяются.

### Проекты

- Автосохранение в IndexedDB.
- Несколько независимых проектов: создание, переключение, переименование и
  удаление.
- Автоматическая миграция старого единственного проекта без потери файлов.
- Атомарная запись manifest и связанных файлов.
- Сохранение последнего целостного checkpoint при неудачной записи.
- Проверка полноты файлов при восстановлении.
- Импорт и экспорт проекта ZIP, повторная привязка исходников.

### Оформление

Акцент, фон рабочего пространства, фон панели и шрифт настраиваются независимо
и сохраняются на устройстве.

## Проверка

```bash

```

## Ограничения MVP

- RAW, TIFF, HEIC и 16-битный конвейер не поддерживаются.
- Мягкость кожи использует приближённую цветовую маску, а не сегментацию лица.
- Heal смешивает окружающие пиксели и пока не переносит фактуру как
  профессиональный Healing Brush.
- Отмена проверяется между асинхронными стадиями. Длительный синхронный
  пиксельный проход нельзя прервать до его завершения.
- Preview ограничен по размеру, а экспорт может обрабатывать полный кадр.
  Некоторые радиусы эффектов могут визуально отличаться.
- E2E проверяет один настоящий JPEG 24 МП с экспортом 1280 px. Производительность
  серии полноразмерных 24–40 МП пока не подтверждена.
- Результаты пакетной обработки хранятся в памяти вкладки до ручного
  освобождения, удаления серии или перезагрузки.
- История версий checkpoint внутри проекта пока отсутствует: хранится последняя
  целостная версия каждого проекта.
