# Pixmuse

Локальный MVP пакетной цветокоррекции фотографий по обработанному эталону.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала, выберите эталонный обработанный кадр, добавьте
JPEG/PNG-фотографии и запустите обработку.

В разделе «Ретушь» доступны экспозиция, контраст, насыщенность, теплота и
мягкость кожи. В «Моём профиле» можно выбрать акцентный цвет интерфейса или
установить собственный. Выбор сохраняется локально.

## Проверка

```bash
npm test
npm run build
```

## Ограничения MVP

Алгоритм переносит средние значения и цветовой контраст RGB-каналов с
регулируемой интенсивностью. Мягкость кожи использует приближённую цветовую
маску и пока не распознаёт лицо или отдельные дефекты. RAW и TIFF пока не
поддерживаются.
